## Overview

The skill makes editorial, high-energy motion reels of the kind used for product films, showreels and site intros,
entirely in code: the time budget, storyboarding, typographic animation, three.js generative layers, shape-continuity
transitions, a synthesized score and the final encode. Every image and every note is generated by code; no image,
video or audio generation model is involved.

The bundled look is the **DeepSeek deep-sea system**: abyss navy → DeepSeek blue → surface aqua → foam, a fish mark
built from a drop of light, a particle "deep", a caustic "current", a "pod" of particles that condenses into a school of
fish, and a beat-locked synth score with sonar pings and water drips. It is a graphic system, not a mascot film: the
fish appears only as the mark, at the scale a mark should.

## How It Works

1. **Time budget and storyboard.** The agent decides which part leads and how much runtime each part gets, then writes
   a shot list: headline, visual mechanism, transition in, sound.
2. **Drawing.** Each shot is a JavaScript function that paints the whole frame: a 2D canvas for type and diagrams,
   three.js layers for the generative backgrounds, a WebGL post pass for RGB split, slice glitch and grain. Every frame
   is a pure function of time.
3. **Review.** Contact sheets, full-resolution stills and transition strips are rendered in headless Chrome, reviewed
   and revised.
4. **Score.** A small synthesizer in Node reads the same `cues.js`, so every hit lands on its frame.
5. **Output.** Frames render in parallel (tens of milliseconds each) and ffmpeg encodes the MP4 with the score muxed in.

## Characteristics

- **Type-led design:** condensed display type (Anton) for headlines, a wide grotesk (Archivo Black) for slams, one
  italic serif voice line, mono micro-type in a fixed HUD grid, and a Chinese counterweight (Noto Sans SC).
- **A mechanism in every shot:** a request hopping through INPUT → REASON → ANSWER, a particle school condensing, a
  zoom that dives through a mark rather than cutting.
- **Shape-continuity transitions:** iris from a dot, zoom through a circle, push down a depth level, grid dissolve.
- **Beat-locked picture and sound:** both read one 120 BPM timeline; transitions use in-key swells and bells, never
  noise whooshes.
- **Honest data:** on-screen numbers only from the provided source and labelled with its scope; illustrations are
  labelled `SCHEMATIC`.

## Example: 深海 · 大肥鱼 (18 s)

The template itself is a runnable 18-second DeepSeek film: the deep, the mark, the signal, the principle and the name.
The encoded film is [docs/deepseek-reel.mp4](docs/deepseek-reel.mp4) (1280×720 web copy; re-render at full size with `render.mjs`); its storyboard is
[template/STORYBOARD.md](template/STORYBOARD.md). Use it as the reference for pacing, spacing and sound; replace its
words with yours.

## Requirements

- Claude Code (or any agent that can read this Skill and run commands) with access to a coding-capable DeepSeek model
- Node.js, Google Chrome (or Chromium / Edge), ffmpeg

## Installation

See the [collection README](../../README.md#installation). As a Claude Code plugin:

```
/plugin marketplace add <you>/deepseek-video-skills
/plugin install kinetic-reel@deepseek-video-skills
```

or copy/link this folder into `~/.claude/skills/kinetic-reel` (or `.claude/skills/` in a project).

## Usage

Describe the reel, for example:

> Make a 45-second DeepSeek-style kinetic reel for our new model release; the demo should lead.

or invoke `/kinetic-reel`. It scaffolds a project from `template/`, presents a storyboard, builds and reviews each shot,
synthesizes the score and writes `out/reel.mp4`.

## Directory Structure

| path | description |
|---|---|
| `SKILL.md` | the workflow and rules the agent follows |
| `template/` | engine and demo: `reel/reel.js`, `reel/cues.js`, `reel/index.html`, `music/score.mjs`, `render.mjs`, `STORYBOARD.md` |
| `scripts/new_project.mjs` | project scaffolding and toolchain check (Node, cross-platform) |
| `references/style-guide.md` | palette, typography, layout grid, motion helpers, GL layers, transition catalogue |
| `references/sound.md` | the synthesizer, transition sound rules, arrangement, known pitfalls |
| `examples/site-intro/` | the reel as a website entry page (HTML/CSS/JS), with a Cloudflare Worker for HTTP Range |
